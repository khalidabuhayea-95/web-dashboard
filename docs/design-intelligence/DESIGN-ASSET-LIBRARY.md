## Taxonomy (folder plan)
- **Canva:** `magnific/<category>/<style>`
- **Magnific:** one project per collection

| Group | Items | Format | Min resolution |
|---|---|---|---|
| Calligraphy lockups | دعوة زفاف، عقد قران، مبارك التخرج، رمضان كريم، عيد مبارك… | SVG (recolourable) or transparent PNG | 2000 px wide |
| Islamic geometry | 8/12-point girih tiles, borders | SVG | vector |
| Arabesque ornaments | corners, dividers, medallions | SVG / PNG | 1500 px |
| Floral / botanical | rose clusters, eucalyptus, beds, arches | transparent PNG | 2000 px |
| Frames | arch, oval, mihrab, torn paper, polaroid | PNG with transparent centre / Canva frames | 1080 px |
| Metallic textures | gold foil, silver, rose gold | JPG tile | 2048 px |
| Paper textures | linen, kraft, cotton, parchment | JPG | 2048 px |
| Watercolor washes | blush, sage, sky | PNG | 2048 px |
| Backgrounds | 9:16 / 4:5 empty scenes per style | JPG | ≥1080×1920 |
| Objects | rings, cake, balloons, cap, products podiums | transparent PNG | 1500 px |
| Icons | date/time/location/phone/social | SVG (Canva icons are fine) | vector |
| Stickers | birthday/kids 3D | PNG | 1000 px |
