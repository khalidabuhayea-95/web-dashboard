# Composition Rules (RTL-aware)

## Core principles
- **Hierarchy:**
  - Level 1 (hero) takes roughly 30–45% of the visual weight.
  - Level 2 (names/key message) takes roughly 20%.
  - Level 3 (details) is quiet.
- **Reading order in RTL:** the eye starts top-right and moves leftwards. In split layouts the text goes on the right and the image on the left, unless the image is the hero.
- **Negative space:** at least 8% margin on every side for social formats and 10% for invitations. Andalusi invitations keep 12–18% side margins.
- **Alignment:** everything snaps to a centre axis OR a right edge. Never mix the two in one block.
- **Proximity:** group info lines (date, time, venue) as one block, using icon + text rows or a 3-cell date strip.
- **Repetition:** reuse one ornament motif. Keep to a maximum of two decorative families.
- **Scale contrast:** the hero should be at least 3× the body size. Weak contrast reads as amateur.

## Layout patterns (pick one per design)
| Code | Pattern | Use |
|---|---|---|
| A | **Central axis**: calligraphy hero → names → body → date strip → venue | invitations (most Andalusi wedding templates) |
| B | **Arch/Mihrab frame**: content inside an arch, ornament outside | Islamic, Ramadan, عقد قران |
| C | **Bottom bed**: floral/object bed in the lower 30%, text above | floral weddings, birthday |
| D | **Hero object + headline + CTA bar** | product, sale, food |
| E | **Giant numeral** (%, age, date) as the graphic | sales, birthday, countdown |
| F | **Split** (RTL text right / visual left) | FB covers, YouTube, business cards |
| G | **Typographic poster**: the phrase is the artwork | quotes, calligraphy posters |
| H | **Grid / steps**: numbered modules | infographics, menus, resumes |
| I | **Envelope / object mock**: card sitting in a scene (envelope, door hanger, table) | premium invitations |
| J | **Photo frame hero**: a real Canva frame plus a decorative border | birthday, graduation, baby |

## Story format safe zones (1080×1920)
- Top 220 px and bottom 300 px: no critical text.
- Hero text centre band: y 500–1100.

## Grids
- Social 1080: 12-col, 60px margins, 24px gutter.
- A4 print: 3 mm bleed, 10 mm safe.
- Invitation info block: label/value pairs right-aligned. The date strip uses 3 cells: day | big date | month.

## Balance checks before export
1. Squint test: is exactly one element dominant?
2. Flip test: is any side visibly heavier without intent?
3. Edge test: nothing within 4% of an edge unless it bleeds on purpose.
4. Clash test: text never sits over a busy texture without a scrim or panel.
