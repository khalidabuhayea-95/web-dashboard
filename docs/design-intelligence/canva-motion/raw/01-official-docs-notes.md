# Raw notes: official Canva pages (read 2026-11-05 in Chrome)

## help/animate-designs (Arabic machine translation, read in full)
- Toolbar "Animate" (تحريك / UI label «إضافة حركة»). Tabs: Page / Element / Text.
- Hover = preview. Click = apply.
- "For selected animations": speed preset (Slow/Medium/Fast) OR exact intro/outro duration (duration controls).
- General or suggested animations can be combined with add-on effects.
- Available styles differ by selection type: text, graphic, shape, photo, video.
- Pro icon on some animations and transitions.
- Remove animation button.
- Click-to-appear (presentation): Click order list, drag handles.
- Element timing: floating toolbar More → Show element timing. Boxes appear in the thumbnail strip; drag to reorder, drag left/right handles for duration.
- Create an animation: drag element along a path; adjust motion style, presentation settings and add-on effects; Done or Delete path.
- Multi-select + Create animation for sequence.
- Video fade: Animate → General → Fade → On enter / On exit / Both + speed. Fades picture only; audio fade separate.
- Reduced motion on device: animations reduced; transitions, background animations, masks and overlays removed.
- Limits: one animation max 10 s; design max 50 animations.
- Share/download as video or GIF.

## en_au/help/page-transitions
- Not in Docs. Video designs add transitions differently (timeline).
- Pages thumbnail view → hover thumbnail → More, or hover between thumbnails → Add transition.
- Hover to preview; select to apply; side panel shows more options.
- Duration (seconds) slider 0.1–2.5 s, or number field.
- Direction options depend on transition.
- Change: click the icon between pages.

## en_au/help/shader-animation (videos only, Pro, gradual rollout)
- Video element → Animate → Featured: Shake Zoom (intensity slider), Whip Slide (speed slider), Old TV, Chroma Wave.
- On enter / On exit / Both. MP4 only.

## features/text-animations (marketing)
- Mentions pop, fade, flicker, pan, tumble, typewriter, neon flicker; motion path "drag in your preferred motion path"; "Pop" makes each character bounce.

## help/using-magic-animate
- AI picks animations for the whole design. Animate → Page tab → Magic Animate.
- "Recommended style" plus alternative styles; "Remove Magic Animate".
- Only presentation, social media and video design types.
- features/magic-animate and en_au/help/magic-animate return 404 (checked).

## help/creating-and-editing-videos
- New multi-track timeline (Oct 2025+): main track, upper tracks, audio. Playhead, ruler, zoom, split (S), slip.
- Element timing ≠ animation duration. Animation speed/duration (intro/outro) in Animate panel; speed preset or precise intro/outro durations "for select animations".
- Transitions only between clips on main track in video designs; duration + direction.

## learn/how-to-use-text-effects-animations
- Mentions 'Wipe' and 'typewriter' to hold focus "as each word and letter appears"; motion path for cinematic layering. Little technical detail.
